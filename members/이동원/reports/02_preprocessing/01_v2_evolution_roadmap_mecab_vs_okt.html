시나리오 B v2 alpha 분석 후보

v2-alpha-1: Okt 사용자 사전 (Mecab 없이 신조어 대응)

  • Okt는 사용자 사전 직접 지원 ❌ → 사전·후처리 결합 전략
  • 토큰화 후 정규식 후처리: ("스코프", "1") → "스코프1" 결합 규칙
  • 가이드 위반 0건 (직접 검토 후 규칙 적용 — 위반금지 #3 준수)

v2-alpha-2: ngram 기반 합성어 보강

  • Okt는 "온실가스" → "온실+가스" 분리 → bigram으로 "온실 가스" 합성 → seed 매칭률 회복
  • scikit-learn TfidfVectorizer의 ngram_range=(1,2) 활용
  • vocab 크기 폭증 → min_df / max_df 조정 함께 검토

예상 결과 (둘 중 하나):
  1. 성공 (Visual C++ Redistributable 있음, 대부분의 Windows) → 시나리오 A 채택. 02 노트북 Run All 시 tokenizer_used='python-mecab-ko' 자동 선택. 추가 설정 없음.
  2. 실패 ("Could not build wheels" 또는 DLL 오류) → 시나리오 B Okt fallback 자동 채택. 02 노트북 Run All 시 tokenizer_used='okt'. 보고서 §5에 실패 reason 1줄 추가하면 끝.

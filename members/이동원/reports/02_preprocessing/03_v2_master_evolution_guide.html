발견 1: Mecab 미선택 — tokenizer_used = 'okt' (시나리오 B fallback)

사용자가 pip install python-mecab-ko 완료했음에도 esg_features.parquet의 tokenizer_used 컬럼 값 = 'okt'. Step 1.1 후보 순회에서 mecab 인스턴스 생성 실패로 Okt fallback. 가능한 원인:

  1. python-mecab-ko import는 됐지만 MeCab() 인스턴스 시 사전 경로 못 찾음
  2. 노트북 실행 시점에 python-mecab-ko 후보가 노트북에 아직 추가되지 않았음 (시간 순서)
  3. uv 가상환경과 Jupyter 커널이 다른 환경 (notebook이 시스템 Python 사용)

v2 fix (카테고리 A): Step 1.1 출력에 TOKENIZER_ERRORS dict 전체 표시 + 사용자에 디버깅 안내

발견 2: esg_features.parquet 9행 중복 (원인 명확 — merge cartesian)

shape=(9, 30) — Samsung 1건이 9번 반복. 원인 진단 완료:

collection_log.csv = 3행 (Samsung 1건 × 노트북 3번 실행으로 append 누적)
  ↓ Step 2 build_corpus → corpus_body 3행
  ↓ Step 9 corpus_body.merge(log_lookup, on=['stock','year'])
  ↓ log_lookup도 3중복 → 1:N cartesian = 3 × 3 = 9행

v2 fix (카테고리 A): Step 2 입력 로딩 셀에 collection_log.drop_duplicates(['stock_code','fiscal_year'], keep='last') 한 줄 추가. 또는 01 collection의 append 패턴을 upsert로 변경.

발견 3: Samsung 1건만 입력 (FastText / Spearman 의미 약함)

이는 의도된 v1 한계. Phase 2B 전체 corpus 입력 시 자연 해결. 본 가이드 §A "데이터 quality 카테고리"의 main work.

발견 4: CSV 한글 인코딩 (utf-8-sig patch 완료)

v1 patch로 모든 to_csv·read_csv·open에 encoding="utf-8-sig" 적용. expanded_dictionary 저장 시 CSV + xlsx 동시 생성으로 Excel 한글 보장. esg_features도 parquet + xlsx 동시 출력. 완료 ✅

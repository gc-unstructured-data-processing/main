B. 10단계 진단

1
치명

N=1 — 모든 통계 NaN (scipy 표준 동작)

spearmanr·ttest_ind·OLS 모두 N≥3·자유도 ≥ 1 필수. 해결: 사이클 3 phase2B Run All → N=31 → NaN 자동 해소 (코드 변경 0줄).

2
주의

OLS만 — ordered_logit·binary_logit 코드 부재

가이드 03 line 220-274가 3 옵션 비교 의무. 본 v1은 OLS 코드만 build. 발전: v2에서 statsmodels.miscmodels.OrderedModel + Logit 추가 + 모형 선택 근거 보강.

3
주의

median split t-test — 그룹 N=0 위험

현재 esg_grade_num ≥ median vs < median. N=1이면 high=1·low=0이라 NaN. 발전: A 이상(≥4) vs 미만 binary split + 그룹 N 명시.

4
발전

cheap-talk specificity 단순화

본 v1은 (숫자 토큰)/총 토큰. 알파: 숫자·연도·금액·단위 분리 카운트 + commitment ratio ("계획·목표·달성") + non-material share (반복 어휘) — 3종 다중 통제.

5
발전

9 쌍 — 차원 정합성만

현재 (feature_E, esg_grade_num), (feature_E, e_grade_num) 등. 발전: cross dim 추가 — feature_E ↔ s_grade_num (특정 차원 신호 다른 차원에 노출 검증).

6
발전

모형 선택 — 정량 비교 부재

현재 표 형식만. 발전: AIC·BIC + 결과 해석 가독성 score 표 + 3 모형 결과 cross check (가이드 03 line 261-269).

7
알파

업종별 분해 (가이드 04 §3-1)

company_master.industry 활용. 전기전자·금융·화학·제조 4분류 × OLS 분해. 알파 후보 #2 — 1개월 일정 적합도 ⭐⭐⭐.

8
알파

section_weighted score

현재 firm-year score = II+IV+VI body concat. 알파: w_II·score_II + w_IV·score_IV + w_VI·score_VI. 3개 weight 비교 (0.5·0.2·0.3 / 0.33·0.33·0.33 / 0.4·0.3·0.3).

9
알파

KLUE-RoBERTa baseline

TF-IDF cosine 대비 dense vector cosine 비교. D-Day 후 알파 후보 #4 — 인프라 부담 ↑.

C. NaN의 numpy/scipy 근본 원인

함수N=1 동작최소 요구

scipy.stats.ttest_ind그룹별 분산 없음 → NaN각 그룹 N ≥ 2

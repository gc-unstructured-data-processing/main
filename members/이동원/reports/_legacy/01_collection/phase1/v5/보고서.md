## 1. 목적 (Why)

### 1.1 v4 → v5 존재 이유

v4는 viewer 4/5 통과 + SECTION-1 14 노드 정확 식별로 **표면적 게이트는 통과**했으나, 4가지 영역 추가 검증 결과:

1. **🚨 VI 섹션 81%가 표** — "이사회 등 회사의 기관" 본문 5,653자 / 표 23,700자 / 합계 29,728자. G 차원 ESG passage의 대부분이 표에서 추출됨
2. **단순 평탄화의 양면성**:
   - 표 포함 시 "온실가스 18,070,212 17,337,196 19,285,537" 같은 수치 문장이 passage로 잡힘 (잡음 가능성)
   - 표 제외 시 VI 본문 5K자만 남아 G 차원 passage 거의 0이 될 위험
3. **정정공시 fallback 미대응** — (2024.06) 분기보고서만 있는 회사에서 v4는 `FAIL_LIST` (가이드 line 172 가짜 0 ❌ 위반금지 강화 필요)

**사용자 지적의 정당성**: "데이터 수집 문제점이 있지만 데이터 전처리로 넘어가는 것"은 좋지 않다 → v5에서 수집 단계의 완성도를 한 단계 더 높임.

## 3. 방법 (What & How) — v4 → v5 변경

### 3.1 Fix #12 (신규) · 표/본문 분리 (Step 6)

```python
# 전체
section_text = ' '.join(t.strip() for t in s1.itertext() if t and t.strip())
# 본문만 (표 제거)
s1_no_tbl = deepcopy(s1)
for tbl in s1_no_tbl.findall('.//TABLE'):
    tbl.getparent().remove(tbl)
section_body = ' '.join(t.strip() for t in s1_no_tbl.itertext() if t and t.strip())
# 표만
section_tables = '\n\n'.join(
    re.sub(r'\s+',' ',''.join(tbl.itertext())).strip()
    for tbl in s1.findall('.//TABLE')
)
```

**근거**:
- v4 검증에서 VI 81% 표 발견 — 단순 평탄화는 G 차원 passage 정확도 영향
- dart-fss-text MVP는 평탄화이나, 본 프로젝트 ESG 가설은 서술 본문이 primary
- 02_preprocessing에서 body / tables 중 선택 가능 (분석 유연성)

### 3.2 Fix #13 (신규) · 정정공시 fallback (Step 4)

```python
REPORT_FALLBACK_ORDER = [
    ('PRIMARY_BIZ', 'A001', '사업보고서', '12'),

    ('FALLBACK_Q3', 'A003', '분기보고서', '09'),
```

각 fallback 시 `status='WARN_FALLBACK_HALF'` 등으로 명시. 위반금지 #1 (가짜 0 ❌)을 더 강화.

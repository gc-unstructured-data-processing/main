Finding 1 사이클 2

한글 폰트 missing — 시각화 깨짐

  • 증상: 사용자 환경에서 "font not found" 경고 + 시각화 PNG의 한글 글자 깨짐
  • 원인: matplotlib이 Malgun Gothic 자동 detect 실패. plt.rcParams['font.family']에 단순 list 지정만으로는 미설치 시 fallback 없음
  • Fix A 패치: font_manager.fontManager.ttflist로 시스템 폰트 query → 우선순위 검색 → 매칭 폰트 자동 등록. 모두 실패 시 한국어 추정 폰트 5개 리스트 + pip 안내
  • 적용: 4 노트북 + 진단 노트북 모두 cell 1·2에 동일 셀 삽입
Finding 2 사이클 2

stock_code int 변환 — silent 오매칭 직결 위험

  • 증상: esg_features_v2.xlsx에서 stock_code가 5930으로 출력. 6자리 → 4자리 leading zero 손실
  • 원인: pandas to_excel은 dtype info 미보존. 다음 노트북이 read_excel 시 int로 인식 → join 시 silent 오매칭 (위반금지 #7 직결)
  • Fix B 패치: 모든 pd.read_csv(..., dtype={'stock_code': str}) 직후 str.zfill(6) 강제. to_excel 직전에도 astype(str).str.zfill(6)
  • 적용: 5 노트북 (00·01·02·02b·03) 모두 패치 완료

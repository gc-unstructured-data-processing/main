N=1 통계 추정 불가 (모든 NaN의 진짜 원인) 치명

관찰

03_mining_v1 Run All 결과 feature_validity 함수가 9개 (feature, grade) 쌍 모두에 대해 NaN 반환. validity_df 출력 표 전체 NaN.

데이터 근거
0  seed_tfidf_E  esg_grade_num  1  NaN  NaN  NaN  NaN
1  seed_tfidf_S  esg_grade_num  1  NaN  NaN  NaN  NaN
... 9 rows total, all NaN

특히 n=1 컬럼 — 표본 크기가 항상 1로 출력. 02_preprocessing_v2가 esg_features_v2.parquet에 1행만 생성한 결과.

원인 (numpy/scipy 동작 표준)
  • scipy.stats.spearmanr 내부: 두 벡터의 순위(rank) 계산 후 Pearson 적용. N<3이면 rank의 분산 = 0 → 분모 0 → NaN. RuntimeWarning도 발생.
  • scipy.stats.ttest_ind: 표본 분산 = 0이면 NaN. 그룹별 N≥2 필수.
  • statsmodels.OLS: 자유도 부족 (관측 - 모수 < 0)으로 적합 자체 불가능.

본 함수들이 NaN 반환은 numpy/scipy 표준 동작. 이는 결함이 아니라 정상 동작.

해결 — 즉시 (사이클 3)
  • 01_collection_phase2B_v1.ipynb Run All — KCGS 등급 stratified 30건 batch 수집 (5~10분)
  • 02_preprocessing_v2 재실행 → esg_features_v2.parquet (~31행)
  • 03_mining_v1 재실행 → Spearman ρ + p + t_stat 모두 정상 값. Gates: N ≥ 3 (Spearman), N ≥ 5 (OLS 추천)
  • 코드 변경 0줄 — N만 늘리면 NaN → 실제 값으로 자동 대체

C. NaN 근본 원인 — 왜 N=1에서 모든 통계 함수가 NaN 반환하는가

3개 함수(spearmanr·ttest_ind·OLS)의 numpy/scipy 내부 동작을 가이드해서 사용자가 결과를 정확히 해석하도록.

1. spearmanr — 순위 분산이 0

scipy.stats.spearmanr(x, y)

x = [0.051]   # seed_tfidf_E
y = [4]       # esg_grade_num
rank(x) = [1]
rank(y) = [1]
Var(rank) = 0
Pearson(rank(x), rank(y)) = Cov/sqrt(Var·Var)
                          = 0/0 = NaN

최소 요구: N ≥ 3 (분산 정의에 N-1 자유도 필요). 가이드 03 line 167-179가 등급의 ordinal 성격 강조 — Spearman은 ESG 등급 적합 검정.

2. ttest_ind — 그룹별 분산 부족

scipy.stats.ttest_ind(high, low, equal_var=False)

median = 4 (esg_grade_num)
high = features[features['esg_grade_num']>=4]['seed_tfidf_E']
     = [0.051]                      # len = 1
low  = features[features['esg_grade_num']<4]['seed_tfidf_E']
     = []                            # len = 0
t_stat = (mean(high)-mean(low)) / sqrt(s²_high/n_high + s²_low/n_low)
       = NaN (Welch 분산 = NaN)

최소 요구: 각 그룹 N ≥ 2 (분산 추정). 본 v1 함수는 if len(high)<2 or len(low)<2: NaN 반환 명시 처리.

3. OLS — 자유도 음수

sm.OLS(y, X).fit() y=N×1, X=N×3 (const+2개)

N = 1
k = 3 (const + seed_tfidf_E + word_count)
df_residual = N - k = -2  (음수!)
β̂ = (X'X)^(-1) X'y
   → X'X = 3x3 행렬, rank = 1 (≠ 3)
   → 비가역 → LinAlgError 또는 NaN

최소 요구: N ≥ k+1 = 4. 실무 권장 N ≥ 10*k = 30 (각 모수당 관측 10개).

결론 — 사이클 3 batch 직후 즉시 해결

예상 사이클 3 후 결과 (N=31)

spearman_rho ≠ NaN  (N=31, df=30)
spearman_p   ≠ NaN  (p ∈ [0,1])
t_stat·t_p   ≠ NaN  (high·low 각 N≥3 가능)
OLS β·SE·p   ≠ NaN  (df_residual=28)
R²           ≥ 0    (적합 가능)

코드 변경 0줄. esg_features_v2.parquet 행수가 1→31로 바뀌면 위 모든 함수 정상 동작.

의미 있는 통계 추정 ≠ 적합 가능 통계 — N=31에서 NaN은 사라지지만, 약한 ρ (0.1~0.2) + 큰 p-value (>0.1) 가능성 있음. 가이드 03 line 188 "ρ가 0.10-0.20 정도면 강한 예측력이 아니라 약한 연관성"으로 해석. NaN 해결 ≠ 가설 입증. 사이클 4 분석에서 해석 디시플린 필수.

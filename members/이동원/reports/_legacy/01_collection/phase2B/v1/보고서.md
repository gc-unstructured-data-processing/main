## 2. 방법

### 2.1 Step 매핑 (phase2A v2와 동일 핵심 + batch 외장)

| Step | What | 시간 |
|---|---|---|
| Safety | Fix A 폰트 + Fix E pandas display | 즉시 |
| 1 | 환경 + phase2A v2 검증 함수 5종 inline | 10초 |
| 2 | 30건 stratified sample 선택 (등급별 5건, seed=42, Samsung 제외) | 5초 |
| 3 | batch run_one_firm_year × 30 (tqdm + rate limit 0.8s) | **5~10분** |
| 4 | collection_log dedup + run_id + 등급 분포 검증 | 5초 |
| 5 | random 3건 viewer URL + top passage (위반금지 #3 검증) | 사용자 수동 |
| 6 | 등급별 SUCCESS/FAIL 분포 시각화 + self-check | 10초 |

### 2.2 평가 기준 (위반금지 #8)
- **SUCCESS ≥ 80%** (24/30 이상) — 통과
- **80% 미만** — 보고서 §한계 명시 + FAIL 사유 분석

### 2.3 batch 격리 — status 11종 + reason
- SUCCESS · WARN_NO_PASSAGES · FAIL_NO_CORP_CODE · FAIL_NO_RCEPT · FAIL_NO_PRIMARY_XML · FAIL_HTTP · FAIL_OTHER 등
- try/except로 각 firm-year 격리 — 한 실패가 batch 전체 중단 안 함

## 4. 한계

### 4.1 시간·API 제약
- 30건 batch 약 5~10분. 381건 전체는 약 1~2시간 (rate limit 0.8s × 381).
- 본 v1은 통계 검증에 필요한 최소 표본 30건만.

### 4.2 stratified imbalance
- S 등급 부족 시 5건 미달 → 등급 변동성 ↓. binary 그룹화 (A 이상/미만)로 대안.

### 4.3 random sampling seed
- seed=42 고정 (재현성 보장)
- 다른 seed로 sweep 시 결과 변동 가능 (보고서 §한계)

### 4.4 viewer 검증 random 3건
- 30건 중 10%만 viewer 직접 확인. 나머지 27건은 알고리즘만 신뢰.
- 권장: SUCCESS 행 중 등급별 1건씩 = 7건 viewer 확인.

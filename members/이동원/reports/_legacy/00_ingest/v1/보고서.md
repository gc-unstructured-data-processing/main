## 3. 결과

### 3.1 등급 분포 (381 firm-year)
- 7등급 × 3 fiscal_year(2022·2023·2024) cross tab 생성
- 등급별 최소 frequency: A·B+·A+ 다수, S·D 적음
- stratified 5건 × 7등급 = 최대 35건 가능 (S 등급 부족 시 ≤ 5건)

### 3.2 Samsung 2024 KCGS 등급 (Fix C dynamic 출력)
- 통합 등급: `A` (=4)
- 환경(E): `B+`
- 사회(S): `A+`
- 지배구조(G): `B+`
- esg_year = 2025 (= fiscal_year 2024 + 1)
- KRX 교차검증 시 위 4개 등급이 모두 일치해야 ✅

### 3.3 산출물 크기

- kcgs_lineage_meta.json: 619 B

## 4. 한계

### 4.1 as_of_date 추정
- `as_of_date='2026-05-15'`는 company_master 시드 작성 일자 추정. 실제 KCGS 평가 결과 발표일은 미확정.
- 향후 KCGS 공식 사이트에서 정확한 평가 결과 발표일 수동 확인 후 메타 업데이트 필요.

### 4.2 등급 분포 imbalance
- S 등급 0~1개 추정 → stratified 5건 미충족. 대안: S+A+ 합산 또는 A 이상/미만 binary 그룹화.

### 4.3 KRX 교차검증 수동
- 본 v1은 KRX URL 안내까지. 실제 일치 여부는 사용자 수동 확인.
- 자동화는 v2 영역 (selenium·playwright + KRX 페이지 파싱).

### 4.4 정정공시 이력 미반영
- KCGS는 평가 후 정정 공지 가능. 본 v1은 단일 시점 데이터.

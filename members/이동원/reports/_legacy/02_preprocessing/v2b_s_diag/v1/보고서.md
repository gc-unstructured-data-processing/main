## 3. 결과 (사용자 Run All 후 채워질 항목)

### 3.1 H1 검증 — seed_S 10단어 빈도 (예상)
| seed_S | II | IV | VI | total |
|---|---:|---:|---:|---:|
| 안전 | ~5 | ~1 | ~0 | ~6 |
| 산업재해 | ~0 | ~0 | ~0 | 0 |
| 중대재해 | ~0 | ~0 | ~0 | 0 |
| 임직원 | ~3 | ~2 | ~2 | ~7 |
| ... | | | | |
| **0회 등장 예상** | 3~5개 (재해·인권 표현) | | | |

→ 결론: **H1 강하게 지지**. seed_S 30~50%가 거의 미등장.

### 3.2 H2 검증 — 누락 의심 어휘 (예상)
| 후보 | total (예상) |
|---|---:|
| 복리후생 | 5~10 |
| 고객만족 | 3~8 |
| 정보보호 | 5~10 |
| 동반성장 | 3~7 |
| 사회공헌 | 5~10 |
| ESG경영 | 5~15 |
| 지속가능 | 5~15 |

→ 결론: **H2 지지**. 5회 이상 등장 후보 5~10개 발견 예상.

### 3.3 H3 검증 — section × dim share
| dim | II | IV | VI |
|---|---:|---:|---:|
| E | ~30% | ~50% | ~5% |
| S | ~15~20% | ~10% | ~5~10% |
| G | ~30~40% | ~30% | ~80~90% |

→ 결론: **H3 부분 지지**. S share가 E·G보다 항상 낮음. 특히 VI는 G 독점.

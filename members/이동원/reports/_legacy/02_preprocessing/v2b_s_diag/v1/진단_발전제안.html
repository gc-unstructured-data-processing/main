B. 10단계 진단

#관찰·발전 영역우선순위
1정규식 패턴 — "복리후생" 단순 매칭만. 단어 조합 (예: "복지·후생") 누락. 발전: pattern 확장 (`복리후생|복지|후생`)🟢 v2
230개 후보 셀렉션 — 직관 기반. 발전: ESG-Kor 라벨 top-k 키워드 정량 추출 → 후보 50개로 확장🟢 v2 (알파)
3단일 firm-year 진단 — 일반화 어려움. 해결: 사이클 3 batch 30건 후 등급별 S seed 등장 패턴 분석🔴 즉시 (사이클 3)
4section_weighted score alt — 본 v1은 단순 합산. 발전: II=0.5·IV=0.2·VI=0.3 weight + 3개 weight 비교🟢 v2
5"산업재해·중대재해" 0회 등장 — Samsung 실제 발생 사례 없음. 일반 firm-year 검증 필요. 해결: 사이클 3 batch 후 등급 vs 재해 표현 분포 분석🟡 사이클 3 후
6VI section 거버넌스 독점 — S 표현 거의 없음. 발전: 별도 ESG·지속가능성 보고서 흡수 검토 (alpha 영역)🟣 알파
7seed_v2 채택 디시플린 — 자동 추가 + 사용자 검토 2단계. 발전: 의미 검토 가이드 1페이지 추가 (어떤 단어가 잡음? 어떤 게 의미?)🟢 v2
8cosine baseline — S 진단 안 함. 발전: cosine_S도 동일 H1·H2·H3 검증🟢 v2
9회사명·연도·법률용어 stopword 추가 후보 — body에 흔히 등장하나 ESG 무관. 발전: 토큰 빈도 top 30 사용자 검토 + stopword v2 채택🟢 v2

B. 10단계 진단

1
치명

N=1 → TF-IDF IDF 무력

1 firm-year corpus면 IDF = ln(1+1/1) = ln(2). 모든 vocab가 동일 idf → 사실상 단순 TF. 해결: 사이클 3 batch 30건 → 정상 IDF.

2
치명

S 점수 ↔ s_grade=A+ 격차 (0.010 vs 최상위)

seed_S 10단어가 Samsung body에 거의 안 등장. 해결 (진행 중): 02b_s_score_diagnosis v1에서 정량 검증 + seed_dictionary_v2_proposed.csv 자동 생성.

3
주의

Okt PRIMARY — Mecab 미설치

Windows mecab-ko 빌드 의존성 어려움. Okt는 신조어 강함이지만 사업보고서 정형 문어체에서 Mecab 대비 정확도·속도 ↓. 발전: koreanize-matplotlib + mecab-python3 wheel 시도, 또는 보고서 §한계 명시.

4
발전

body only — VI 표 80% 손실

VI body=5,653 vs tables=23,686. body only로 G 신호 본문 절반 미만. 발전: v3에서 source = 'body' / 'body+tables' / 'tables' 3종 alt sweep.

5
주의

불용어 16개 — 부족 의심

stopwords_ko_esg.txt는 일반 조사·부사 16개. 회사명·연도 표현·반복 법률 용어 추가 후보. 발전: 토큰 빈도 상위 30개 사용자 직접 검토 셀 — 잘못 보존된 stopword 발견.

6
발전

TfidfVectorizer 파라미터 단순화

min_df=1, max_df=1.0 — N=1이라 의미 없음. v3 발전: N=31에서 min_df=2 (1회만 등장 vocab 제외) + max_df=0.95 (모든 firm-year 등장 일반어 제외) → vocab 효율적.

7
주의

expanded_dictionary 채택 보류

FastText는 N=1에서 vector collapse. 해결 (v3): N=31 학습 + θ 3개값(0.5·0.6·0.7·0.8) sweep + 상위 100단어 직접 검토 + kept_or_removed 채움.

8
발전

cosine 기준 문장 — 가이드 03 line 211 그대로

현재 3 sentence (E·S·G) 고정. 발전: 가이드 외 alt 기준 문장 1~2개 추가 → robustness check. KLUE-RoBERTa dense vector cosine 비교 (알파).

9
알파

specificity score 정교화 (벤치마킹 4번 ClimateBert)

현재 단순 digit 비율. 알파: 숫자·연도·금액·단위 분리 카운트 + commitment ratio 추가 ("계획·목표·달성·할 것" 빈도) + non-material share (반복어휘).

10
충족

위반금지 8항목 + 가이드 04 §3

4·6·7 모두 ✅. 측정 validity는 03_mining에서 Spearman·t-test로 보강.

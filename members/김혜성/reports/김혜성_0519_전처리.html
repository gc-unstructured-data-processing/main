형태소 분석 — Kiwi 명사 토큰화

셀 40 · markdown셀 41 · code셀 42 · code

한국어 형태소 분석기로 Kiwi를 선택하고, 사업보고서 본문에서 명사(NNG 일반명사, NNP 고유명사)만 추출하는 함수를 정의한다.

분석기·품사 선택의 근거

  • 왜 Kiwi인가 — C++ 기반으로 381개(평균 3.4만 자, 최대 19만 자) 처리 속도가 빠르고, 최신 사전·신조어 대응이 좋다. 재현성을 위해 기본 모델을 고정
  • 왜 명사만인가 — 30개 seed 단어가 전부 명사(탄소, 이사회, 공급망 …)이고, TF-IDF의 측정 목적이 "ESG 명사의 빈도"이기 때문. 형용사·동사는 측정 대상이 아니므로 noise로 본다
  • 1글자·숫자 토큰 제외 — min_len=2, form.isdigit() 필터. 1글자 명사는 의미 모호 토큰이 많아 기본적으로 버린다

핵심 함수 — extract_nouns()

def extract_nouns(text, kiwi_inst, min_len=2):
    tokens = kiwi_inst.tokenize(text)
    nouns = []
    for t in tokens:
        # NNG: 일반명사, NNP: 고유명사만
        if t.tag in ("NNG", "NNP"):
            form = t.form.strip()
            if len(form) >= min_len and not form.isdigit():
                nouns.append(form)
    return nouns

STEP 2-3

복합명사 보존 — seed 사용자 사전 등록

셀 43 · markdown셀 44 · code셀 45 · code

Kiwi 기본 분석은 복합명사를 분리한다 — 재생에너지 → 재생 + 에너지, 감사위원회 → 감사 + 위원회. seed 단어가 쪼개지면 TF-IDF 사전 매칭이 원천적으로 불가능해진다. 이 단계가 그것을 막는다.

문제의 본질

TF-IDF는 "토큰 = 단어"로 매칭한다. 재생에너지가 corpus에서 재생 + 에너지 두 토큰으로 흩어지면, seed dictionary의 "재생에너지"와는 영원히 매칭되지 않는다. 즉 측정 대상 단어 자체가 사라지는, 측정의 전제를 무너뜨리는 문제다.

해결 — 사용자 사전 등록

seed_dictionary.csv를 로드해 30개 seed_term을 전부 Kiwi 사용자 사전에 고유명사(NNP)로 등록한다. 그러면 분석기가 이들을 분리하지 않고 한 토큰으로 인식한다.

셀 45 — 사용자 사전 등록 + 30개 일괄 검증

# 30개 seed가 단일 토큰으로 보존되는지 일괄 검증
broken = []
for term in seed_terms:
    toks = extract_nouns(term, kiwi)
    if term not in toks:

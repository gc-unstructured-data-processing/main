알파 후보 상세

각 문서에서 제안된 알파 방향 전체 정리
★ 1순위 추천
Talk–Walk Gap 진단
공시 언어 vs 실제 등급 격차 점수
제안: 김혜성 · v1공동 (알파A 연계)
분량을 잔차화한 순수 ESG 어휘 강도와 KCGS 등급의 격차(gap_d)를 기업별로 정의. 과잉공시형(over-talk) vs 과소공시형(under-talk)을 2×2 사분면으로 유형화하고 재무특성·업종 분포를 비교. 선행연구가 멈춘 "평균 효과"를 기업 단위 진단·처방으로 끌어올림.
talk_d_resid = residual(expanded_score_d ~ log_n_tokens)
gap_d = z(talk_d_resid) − z(d_grade_num)
gap > 0 → 과잉공시(greenwashing 후보)
gap < 0 → 과소공시(IR gap)
추가 데이터 불필요 cheap-talk 직접 통제 기업별 처방 가능 KCGS 역인과 주의
★ 가독성 지도
A+B+C 통합 — 가독성 지도
분량·차원·섹션 3축 통합 검증
제안: 김지우
"분량 vs 내용(A) · E/S/G 차원별(B) · 섹션 국소화(C)"를 따로 쓰면 일부 답만 나오지만, 세 축을 합치면 분량을 걷어낸 뒤 어느 차원이 어디서 읽히는지 하나의 완결된 그림이 된다. D(측정 방법 강건성)는 보조 robustness로 편입.
A: 분량 통제 후 잔존 신호 확인
B: E·S·G 차원별 등급 연관 분해
C: II·IV·VI 섹션별 신호 국소화
D: 사전 vs 임베딩 강건성 (보조)
완결된 스토리 기존 feature 활용 분석량 多
후보 A
Cheap-talk 제거 후 순수 G 신호
분량 잔차 G어휘 → 알파 팩터
제안: 신지영 · v1공동
G어휘 빈도에서 분량 효과를 제거한 잔차를 팩터로 구성. "분량만 늘린 기업"과 "진짜 G 내용 기업"을 시장이 구별하는지 검증.
G_signal = G어휘 빈도 / 전체 분량
→ 분량 회귀 잔차 추출
→ 잔차 상위 vs 하위 포트폴리오 수익률 비교
선행연구 공백 직접 타격 실행 용이
후보 B
VI 섹션 집중 분석 팩터
G신호 국소화 → 섹션 한정 검증
제안: 신지영 · v1공동 (알파D 연계)
G 신호가 VI 섹션에 국소화된다는 발견을 활용. VI 섹션만 추출해 Sentence Transformer 임베딩 → G 어휘 밀도 팩터 구성. 전체 보고서 대비 VI 섹션 한정 신호의 알파 예측력을 비교.
VI 섹션 텍스트 → KR-ELECTRA 임베딩
→ G 어휘 밀도 팩터
→ 전체 보고서 대비 예측력 비교
차별적 발견 섹션 분할 정확도 의존
후보 C
중대성(Materiality) 가중 어휘 신호
업종별 E·S·G 중대성 가중치 적용
제안: 김혜성 (2순위)
Khan-Serafeim-Yoon(2016): 업종별 중대 이슈에서만 초과성과. E 신호가 재무통제 후 소멸하는 것이 중대성 관점과 정합적. 업종별 E/S/G 중대성 가중치 부여 후 등급 설명력 변화 검증.
mat_score = Σ_d w(ind,d) × z(expanded_score_d)
ρ(mat_score, esg_grade) vs ρ(equal_score, esg_grade)
→ 중대성 가중이 설명력을 높이는가?
이론 근거 강력 업종 매핑 판단적 민감도 분석 필수
보조
Within-firm 변화 분석
기업내 연도별 공시 변화 → 등급 반응
제안: 김혜성 (보조 robustness) · v1공동 (알파C 연계)
기준 분석은 횡단면(pooled). G 신호가 기업 간(구조적) 특성인지 기업 내(연도별 대응)인지 분해. 3개 연도 1차 차분/기업 FE 활용. 단, within 분산이 작아 검정력 약함.
Δg_grade ~ Δexpanded_G + Δlog_n_tokens
→ between vs within 분산 분해
→ G신호: 구조적 유형 vs 연도별 전술?
robustness 보조 3년 검정력 약함

오늘 회의 안건

01
알파 주제 최종 확정
Talk–Walk Gap + 가독성 지도 통합 방향에 동의하는가? 메인 알파와 보조 알파(중대성 가중) 병행 여부 결정.
결정 필요
02
cheap-talk(분량) 전면 배치 수위
발표에서 분량 교란을 얼마나 강조할지. "최강 신호 = 분량" 자체가 핵심 발견으로 전면에 나올지 여부.
토론
03
S "측정 불가" 표현 방식
S 약신호를 "본질적 한계"로 볼지 vs "사업보고서 통로의 한계"로 볼지. 후자가 방어적이나 뉘앙스 차이 조율 필요.
토론
04
규제 제언 강도 결정
표본 381 firm-year = pilot 수준. 규제 권고를 "검토 권고"로 완화할지, 결론 섹션에서 얼마나 강하게 낼지.

ESG DART · 3조 · 알파분석 회의 입장 자료

알파분석 설계와 시사점은 타당한가,
그리고 나는 무엇을 더 내세울 것인가

지난 회의에 불참한 이동원이, 회의에서 메인으로 확정된 김혜성의 Talk–Walk Gap 알파(노트북 §6에 이미 구현됨)와 「알파분석_제안_김혜성」·「알파분석_설계_explainer」를 정독해 작성한 검토 의견서다. 오늘 안건은 ① 설계 타당성 확인 → ② 시사점·제언 타당성 확인 → ③ 추가 의견 개진 → 제언 최종 결정이다.

작성 이동원 (통합·문서·발표자료) 메인 알파 Talk–Walk Gap (김혜성) 표본 381 firm-year · 추가수집 0 톤 중도~적극
회의 합의 전제

메인 알파 = 김혜성 「말–실행 격차(Talk–Walk Gap)」로 확정

비교자료 평가매트릭스에서 Talk–Walk Gap과 가독성 지도가 동률 15/15였고, 이미 노트북 §6에 전 과정이 구현·실행되어 있다(격차점수 → 2×2 유형 → 지속성 → 규모통제 robustness → 축간 선택적 공시). 따라서 이 문서는 "어떤 알파를 할까"가 아니라 "확정된 김혜성 알파의 설계·시사점이 타당한지 검증하고, 무엇을 더 강하게 내세울지"에 집중한다. 근거: §6 구현 · 비교자료 매트릭스

1
안건 ① · 알파분석 설계가 타당한가

설계 4결정 + 견고성 점검 — 항목별 검증

격차 점수를 만드는 4가지 설계 결정(Decision Box ⑭)과, 가장 중요한 견고성 점검(6-4B)을 하나씩 "타당 판정 + 근거(수치) + 내 보강의견"으로 검토한다.

설계 결정별 판정

① 분량 잔차화 — talk_resid = resid(expanded_score ~ log_n_tokens)
타당 ✓
근거. §4 타당성 검증에서 보고서 분량(n_tokens)이 어떤 ESG 어휘보다 등급과 강하게 연관(ρ≈0.66)된, 이 프로젝트 최대 교란이다. 그 분량으로 설명되는 몫을 'talk'에서 직접 빼고 길이와 무관한 순수 어휘강조도만 남긴 것은 정확히 옳은 통제다. 검증 출력 talk_resid↔log_n_tokens r≈0.000 — 분량을 깨끗이 제거했다.
보강 →r≈0.000·gap 평균≈0은 "발견"이 아니라 "제대로 만들었다는 검증 표시"다(잔차는 수학적으로 그 변수와 상관 0). 발표 때 이걸 결과처럼 읽으면 안 된다고 못 박자. 실제로 읽을 값은 SD 1.079(격차의 폭)와 개별 z다.
② z-표준화 후 격차 정의 — gap = z(talk) − z(grade)
타당 ✓
근거. 한쪽은 연속값(어휘), 한쪽은 0~6 서열(등급)이라 그대로 빼면 비교가 안 된다. 각각 z로 맞춘 뒤 빼는 것은 표준 절차이며, '공시점수 − 성과점수'로 격차를 만든 greenwashing 선행연구(#6 Peeking, Delmas-Burbano 계열)와 동형이다. 양수=과잉(말이 앞섬), 음수=과소(등급이 앞섬)로 부호 해석도 명료.
보강 →양극단이 직관과 일치해 설계 타당성이 눈으로 확인된다: 과잉 1위 백광산업(3년 연속 D인데 어휘 z +1.2~1.6), 과소 1위 KB·신한금융지주(A+인데 어휘 z 음수). "격차가 의도대로 잡힌다"의 산 증거.
③ 2×2 중앙값 분할 + 3개 연도 지속성
타당 ✓
근거. 등급이 특정 구간(s_grade A+ 112건 등)에 쏠려 평균이 대표값이 못 되므로 중앙값 분할이 더 적절(표본이 고르게 절반씩 나뉨). 유형 분포(과잉 72·과소 96·정합 119·일관저조 94)도 한쪽 쏠림 없이 분포. 지속성: 127개사 중 76개사(59.8%)가 3년 내내 같은 칸 → 격차가 일시적 전술이 아니라 기업에 굳어진 특성임을 보인 강력한 결과.
보강 →경계선 근처 분류가 흔들릴 수 있으니 칸(유형)뿐 아니라 연속 gap_ESG도 함께 보고하자. 그리고 3개 연도는 지속성 판단에 짧다는 한계를 반드시 같이 명시(검정력 약함).
④ 규모 추가 통제 견고성 (6-4B) — talk ~ log_n_tokens + log_assets
★ 설계의 최대 강점
왜 결정적인가. 6-4에서 유형을 가장 강하게 가른 변수가 규모(log_assets, H=172)였다 → "Talk–Walk 격차란 게 사실 회사 크기를 돌려 말한 것 아니냐"는 반론이 당연히 나온다. 이를 막으려 길이 + 규모까지 동시에 잔차화해 다시 분류한 결과: 원래 격차와 Spearman ρ=0.993, 유형 일치율 90.9%(경계 9%만 재분류). → 격차는 단순 규모 대리가 아니라 규모로 환원되지 않는 독립적 정합성 신호.
보강 →이 robustness가 설계 방어의 핵심이다. 발표에서 "격차=규모 대리 아니냐?"는 예상 반론에 ρ=0.993 / 일치율 90.9%로 선제 차단하도록 슬라이드 전면에 두자.
⚖︎종합 판정 — 설계 타당. 4결정 모두 방법론적으로 옳고, 특히 분량·규모 이중 통제 후에도 격차가 보존된다는 점이 다른 어떤 팀안보다 강한 방어선이다. 유일한 구조적 한계는 3개 연도 패널의 짧은 시계열과 중앙값 경계 민감성이며, 둘 다 연속 gap 병행·한계 명시로 관리 가능하다.

안건 ② · 시사점·제언이 타당한가

핵심 발견 3가지와 제언의 타당성 확인

알파가 산출한 세 발견을 재확인하고, 거기서 나온 시사점·제언이 데이터로 뒷받침되는지(그리고 어디까지만 말해야 하는지)를 점검한다.

핵심 발견 (재확인)

말–실행 불일치
44%
과잉 72 + 과소 96 = 168 / 381. 절반 가까이가 말과 실행이 어긋난다.
구조적(3년 고정)
59.8%
127사 중 76사가 3년 내내 같은 칸. 일시적 전술 아닌 굳어진 특성.
축간 선택적 공시
47.2%
180 / 381이 한 축 과잉·다른 축 과소. ESG를 골라서 부풀린다.

시사점 타당성 점검

시사점 A — "유형을 가르는 건 수익성이 아니라 규모다"
타당 ✓ (통념 반증)
근거. 수익성 roa H=4.59 p=0.205 → 차이 없음 vs 규모 log_assets H=172.0 p<0.001. 과잉공시 roa 중앙값 0.014 ≈ 나머지 0.021(Mann-Whitney p=0.126). → "과잉공시 = 부실기업의 변명"이라는 통념을 데이터로 반증: 과잉공시는 '소형주의 상징적 공시', 과소공시는 '대형주의 IR 격차'.
시사점 B — "S축은 약점을 말로 가리고, G축은 강점을 정당하게 알린다"
★ 타당 + 차별점
근거(6-7 [C]). S를 부풀린 firm-year의 실제 S등급 평균 2.08 ≪ 전체 3.03(약점 은폐), G를 부풀린 곳의 실제 G등급 2.43 > 2.31(정당한 시그널링). → "선택적 공시 = greenwashing"을 단정하지 않고 정교화한다. 단일 ESG 점수로는 결코 보이지 않는 구분 — 이 알파만의 기여.
제언 — 유형별 경영 처방 (과잉=검증근거 보강 / 과소=ESG섹션 응집)
타당, 단 조건부
판정. 제언 자체는 발견과 정합적이고 평가표의 '알파·해석·제언'을 동시에 충족한다. 다만 '처방'이 아니라 '진단 신호 기반 권고'로 묶어야 한다. 과잉공시 11개사(구조적)·과소공시 21개사(금융지주·CJ·현대건설 등)를 1차 점검 대상으로 구체화하되, 인과·성과 단정은 피한다.
⛓︎제언을 묶는 안전장치(반드시 유지). ⑴ KCGS 등급은 noisy하고 사업보고서를 평가 인풋으로 사용 → 동어반복·역인과 위험, 격차는 '진단 신호'지 인과적 greenwashing 증명이 아니다. ⑵ 381 firm-year는 의도적으로 고른 pilot 패널 → "한국 상장사 일반"으로 일반화 금지. ⑶ bag-of-words(명사)라 "배출 증가/감축"을 못 구분. 이 세 한계가 제언을 '검토 권고' 수위로 자연스럽게 한정한다 → 그래서 제언은 타당하다.

안건 ③ · 이동원이 추가로 내세울 의견

김혜성 알파를 더 강하게 만드는 4가지

메인 알파가 김혜성안으로 확정된 만큼, 추가 의견은 모두 그 안을 보강·차별화하는 방향으로 모았다.

A6-7 「축간 선택적 공시」를 우리만의 차별점으로 전면 배치

선행연구의 greenwashing 측정은 거의 전부 ESG를 하나의 점수(공시−성과)로 합친다. Bingler(#4)의 cherry-pick도 기후(E) 내부의 중대/비중대 선택일 뿐이다. 우리는 gap_E·gap_S·gap_G를 분해해 E·S·G 세 축을 각 축의 KCGS 등급에 견줘 비교한다 — "단일 ESG 점수가 구조적으로 못 보는" 유일 기여.

왜 전면에 → 평가표 '알파' 가점의 핵심이자, 선행 13편 어디에도 없는 빈틈을 정확히 겨냥. "S는 약점 은폐(2.08≪3.03), G는 정당 시그널(2.43>2.31)"이라는 한 줄이 발표의 하이라이트가 된다.
Bcheap-talk(분량 ρ=0.66)을 '발견'의 전면에

알파의 출발점이자 정당성의 근거다. "등급과 가장 강하게 연관된 건 ESG의 내용이 아니라 보고서 길이"라는 사실(§4) 자체가 강력한 메시지이며, 그렇기에 talk에서 분량을 빼는 격차 설계가 정당화된다. 분량을 숨기지 않고 전면에 두는 것이 오히려 정직하고 설득력 있다.

왜 → 비교자료 안건 2와 직접 연결. "최강 신호 = 분량"을 핵심 발견으로 내세우는 데 찬성.
C김혜성 Gap + 김지우 가독성 지도 = 하나의 완결 서사로 통합

두 안은 같은 빈틈을 다른 프레임으로 본 것이다. 분량 통제(A·§4–5) → 차원 분해(B·§5) → 섹션 국소화(C, 보조) → 기업별 격차 진단(§6)으로 이으면, 김혜성의 gap은 김지우 가독성 지도의 자연스러운 종착점이 된다. 충돌이 아니라 하나의 이야기 — 메인은 합의대로 김혜성 Gap.

왜 → 발표 스토리라인이 매끄러워지고, 팀 4인의 작업이 한 흐름으로 묶인다.
D신지영의 '주가 수익률 알파'는 현재 데이터로 실행 불가 → 진단 프레임으로 흡수

신지영 제안의 G잔차·VI섹션·워싱·비대칭 팩터는 모두 "포트폴리오 수익률 비교"로 검증을 끝맺는다. 그러나 이 프로젝트엔 주가 수익률 데이터가 없다 — 유일한 'walk'는 KCGS 등급이다. 따라서 수익률 검증은 실행할 수 없고, 대신 walk를 KCGS 등급으로 둔 §6 Talk–Walk 진단으로 흡수한다(워싱 탐지·잔차화 아이디어는 §6에 이미 반영됨). 주가 알파는 §8 후속과제로 정직하게 남긴다.

왜 → 회의에서 "수익률 알파를 본분석으로 올릴지"가 나올 때, 데이터 제약을 분명히 해 무리한 약속을 막는다. 좋은 아이디어를 폐기가 아니라 후속과제로 보존.

안건이동원 입장
1. 알파 주제 최종 확정메인 = 김혜성 Talk–Walk Gap 동의. 김지우 가독성 지도와 통합 서사로 묶고, 김혜성 gap을 종착점에 둠 (위 의견 C).
2. cheap-talk(분량) 전면 배치 수위전면 찬성. "최강 신호 = 분량(ρ=0.66)"을 핵심 발견이자 알파의 출발점으로 (의견 B).
3. S "측정 불가" 표현 방식"본질적 한계"가 아니라 "사업보고서 통로의 한계"(방어적)로. 나아가 6-7의 'S 약점 은폐' 발견과 결합해 약점을 오히려 발견으로 전환.
4. 규제 제언 강도표본이 pilot이므로 규제 권고는 "검토 권고"로 완화. 단 기업·투자자 유형별 제언은 구체적으로(중도~적극). 대상 기업 수(과잉 11·과소 21)까지 명시.
5. 역할 분담이동원 = 통합·문서·발표자료·해석/제언 파트 담당으로 확정 요청.
